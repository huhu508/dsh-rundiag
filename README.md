# DSH rundiag

DSH 右侧栏 rundiag 插件：按日期安排任务、记录完成、合并计划球与完成球，并把 COROS 训练数据整理成每日复盘和教练建议。

> 显示名：`rundiag`；包名与仓库名：`dsh-rundiag`。

## 功能

- 日期时间轴：不再把任务简单分成“今天/未来”，而是按周浏览过去与未来的每一天；过去日期会显示当天的完成情况和复盘入口。
- 任务 / 子任务：树形结构、描述、截止日期、开始日期、优先级、标签；支持列表内联添加、勾选子任务、拖动根任务排序。
- 快速添加：先选任务类型（训练 / 学习 / 工作 / 生活 / 创作 / 其他），再输入标题；支持 `明天`、`#训练`、`!高` 等标记。
- 完成度：勾选完成，或按次数 / 距离 / 时长累计目标；父任务自动汇总子任务完成情况。
- 能量球：为某天创建任务会生成一颗对应类型的计划球；手动完成或 COROS 识别到运动记录后出现同色实际球。球体是透明水晶质感，可自由拖动，带惯性、碰撞回弹和拉伸形变；实际球拖到可匹配的计划球上，会像细胞吞噬一样融合成绿色完成球。COROS 生成的实际球不能删除、取消完成或隐藏。
- 每个球保存完整训练属性：距离、时长、平均 / 最大心率、卡路里、训练负荷、爬升、平均 / 标准化功率、运动类型和活动 ID；详情页的「运动数据」可查看。
- 每日复盘：记录主观疲劳、睡眠质量、肌肉酸痛、心情、训练评分、训练备注和训练日记；自动附上数据疲劳、CTL / ATL / TSB、ACWR、当日负荷、训练评价和教练建议。
- 教练视图：训练准备度、疲劳累积、长期 / 短期负荷、负荷比、单调性、周负荷、14 天负荷图、HRV / 静息心率 / VO₂max / LTHR / 阈值配速 / 耐力、成绩预测和近期训练。
- COROS：支持中国大陆、国际、欧洲区账号或 access token；同步最近 30 天活动及最近 120 天每日指标；活动不会重复计入。识别到今天的活动时，可按运动类型自动生成一条已完成的「今日跑步 / 今日骑行」任务（可在同步页开关）。
- 数据安全：增量操作提交，避免旧页面覆盖同步进度；写入前备份 `state.json.bak`；支持导出完整 JSON。

## 安装

从本仓库安装：

```sh
dsh plugin add github:huhu508/dsh-rundiag
```

也可以在 DSH 的插件安装入口选择 GitHub 仓库 `huhu508/dsh-rundiag`，或下载 [v0.5.0 Release](https://github.com/huhu508/dsh-rundiag/releases/tag/v0.5.0) 中的 `dsh-rundiag-0.5.0.tgz`。安装后刷新一次 DSH 页面。

## 使用

1. 安装或更新后刷新一次 DSH 页面，让 Client 插件重新加载。
2. 打开任意会话的右侧栏，在指南页选择「rundiag」。
3. 顶部切换 `计划 / 复盘 / 教练 / 同步`；在日期条切换日期，任务会自动落在选中的那天。
4. 在「同步」页连接 COROS，可开启「自动同步」和「补齐今日」；每天打开页面或插件启动时会自动同步一次。
5. 数据保存在 DSH profile 的 `rundiag/state.json`，上一版备份在 `state.json.bak`；access token 不会返回给浏览器。

## 快捷键

- `N`：聚焦新任务输入框
- `R`：刷新云端数据
- `Esc`：关闭详情

## 任务类型

计划视图保留六种类型，颜色会映射到能量球：训练、学习、工作、生活、创作、其他。类型在创建任务时选择，也可以在任务详情中修改。

实际球与计划球合并时，不要求属于同一条任务：同类型是前提，再满足任意一项即可融合——同一条任务、同一种运动、距离相差不超过 20%（至少 0.8 km）、时长相差不超过 20%（至少 6 分钟），或带有相同标签。融合会保留计划任务，并把实际球的训练属性写入计划任务；不适合的运动不会被强行合并。

## 数据接口

- `GET /rundiag/api/state`：当前状态 + 教练计算结果（不包含 token）。
- `POST /rundiag/api/ops`：增量操作（新增、修改、删除、完成、排序、合并球、复盘、自动同步 / 自动补齐开关）。
- `POST /rundiag/api/sync`：立即同步 COROS 活动与每日指标。
- `GET /rundiag/api/export`：导出任务、复盘、活动、每日指标 JSON 备份。

## 训练算法

负荷优先使用 COROS 返回的 `trainingLoad`；缺失时按心率储备和运动时长估算。长期负荷使用 42 天 EMA（CTL），短期负荷使用 7 天 EMA（ATL），状态为 `TSB = CTL - ATL`；负荷比使用 7 天 / 28 天（ACWR），并计算 7 天单调性和 strain。训练准备度综合 HRV 基线、静息心率基线、TSB、ACWR 和睡眠评分，输出 5–98 的分数和训练建议。成绩预测使用最近最佳跑步成绩按 Riegel 指数 `1.06` 外推。

这些是公开的运动科学模型，不是 COROS、RQrun、rundiag、Stryd 或悦跑圈的私有算法；数据不足时结果只作趋势参考。

## COROS 说明

COROS 使用非官方 Training Hub API（`teamcnapi.coros.com` / `teamapi.coros.com` / `teameuapi.coros.com`）。接口可能随 COROS 更新而变化，登录也可能使手机 App 的会话失效。插件只保存 token，不保存密码；建议优先使用 token 连接。同步失败时会保留错误信息，不影响本地任务数据。

睡眠明细需要 COROS 移动端接口和独立 token，本插件默认不读取；每日指标中的睡眠评分会在 COROS 网页接口提供时使用。

## 开发

无需构建步骤。`lib/index.js` 是 Host 插件，`lib/client.js` 通过 DSH ModuleLoader 加载；静态检查：

```powershell
node --check lib/client.js
node --check lib/index.js
node --check lib/state.js
node --check lib/coros.js
node --check lib/coach.js
```

安装到当前 DSH profile：

```text
plugin_manager install_bundle <本目录绝对路径>
```
